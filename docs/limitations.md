# Contribution, overlap and limits

The contribution is a compact regression tool combining fictional lifecycle events, positive utility controls, explicit search/get contracts, simple policies, evaluator-owned exact gold and evidence-linked failures. It does not claim to invent memory evaluation or lifecycle operations.

[LongMemEval](https://github.com/xiaowu0162/LongMemEval) covers updates/temporal questions/abstention; [LongMemEval-V2](https://github.com/xiaowu0162/LongMemEval-V2) supplies an agent-memory harness; [LoCoMo](https://github.com/snap-research/locomo) studies conversational memory; [LangMem](https://langchain-ai.github.io/langmem/concepts/conceptual_guide/) covers consolidation/namespaces; [Mem0](https://docs.mem0.ai/platform/features/memory-expiration) documents path-specific lifecycle semantics. Sources/licenses were read on 2026-10-07 and pinned/attributed in PLAN.md/THIRD_PARTY.md. No external code, models or datasets are reused.

Exclusive-second expiry through both paths is our reference profile, not a universal vendor standard. No vendor was evaluated; allowing expired ID reads under a different declared contract is not automatically defective/insecure.

- Structured facts/effective times come from authors; the mock does not understand/extract/reconstruct real-world truth. No LLM, public benchmark, adoption, speed, cost or prompt-injection result is implied.
- Conservative matches this authored gold, without general superiority. Failed baselines stay failed and an empty adapter loses positive utility.
- Tenant binding is logical, without authenticated production principals. Trusted Python can introspect/edit process/repository state; private arguments are not sandbox isolation or benchmark certification.
- Tombstones/expiry exclude supported reads. Inputs, SQLite pages, earlier traces, contexts, backups and outside caches are not erased/unlearned. No privacy/legal guarantee.
- Reopen is connection close/construction at the same file, not crash/concurrent/distributed/asynchronous-service recovery or exactly-once external effects.
- Custom adapters are synchronous, untimed and unsandboxed. Input/read bounds do not cap their resources/side effects. Interrupted reports can be partial.
- No provider/framework/vector DB/UI/MCP/A2A server/external memory deployment is included. Hosted CI/Linux/publication remain unexecuted at M2 handoff.

Inspect trace-linked expected/observed values and add fictional application-specific cases with declared semantics. Real accounts, production data and external backends require separately accepted scope.
